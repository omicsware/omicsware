What we offer

Three core service areas

Every analysis is grounded in published research pipelines, delivered with reproducible code and publication-quality outputs — not generic automated reports.

🧬

RNA-seq Transcriptomics

Comprehensive differential expression and functional analysis for plant, animal, and microbial transcriptomes. From count matrix to manuscript figures.

  • Differential expression analysis (DESeq2 / edgeR)
  • Volcano plots, MA plots, heatmaps
  • GO and KEGG functional enrichment
  • Expression trajectory clustering (Mfuzz / STEM)
  • Transcription factor enrichment analysis
  • Weighted Gene Co-expression Network (WGCNA)
  • Candidate gene identification and heatmaps
  • Multi-comparison UpSet analysis
Most requested
🔬

Whole Genome Resequencing

Population-level and comparative genomic analyses from WGS data. Particularly suited for polyploid species, crop genomics, and evolutionary studies.

  • Variant calling and annotation (GATK / FreeBayes)
  • SNP and InDel filtering and classification
  • Structural variation detection (SVs, CNVs)
  • Genome stabilization analysis
  • Population structure and phylogenomics
  • Selection sweep analysis
  • Comparative genomics across accessions
  • Sub-genome level analysis (polyploids)
Polyploid expertise
🌱

Metagenomics

Microbial community profiling and functional characterization from amplicon and shotgun sequencing data. Soil, gut, environmental, and clinical samples.

  • 16S / ITS amplicon analysis (QIIME2 / DADA2)
  • Taxonomic profiling and diversity metrics
  • Alpha and beta diversity analysis
  • Differential abundance testing
  • Shotgun metagenomics assembly
  • Functional annotation (HUMAnN3 / KEGG)
  • Metagenome-assembled genomes (MAGs)
  • Environmental factor correlation analysis
Amplicon + Shotgun
